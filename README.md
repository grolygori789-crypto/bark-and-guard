# BARK & GUARD — Shih Tzu Defense

Production repository for the mobile-first 2D tower-defense game.

## Current milestone
Stage 1 graybox: validate pathing, Guard Spots, pacing, economy and core combat before final sprites and animation.

## Repository rules
- Keep the repository root minimal.
- Never create filenames such as `final2`, `new`, `latest`, or `v3`.
- Git commits are the version history; files keep stable canonical names.
- Replace/update canonical assets in place when approved.
- One stage owns its assets under `assets/stages/stage-XX/`.
- Character assets live under their species/character folders.
- Generated experiments do not enter production folders until approved.
- Do not commit cache/build junk.

See `docs/design/PROJECT_STRUCTURE.md`.
